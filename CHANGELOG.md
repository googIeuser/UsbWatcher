# Changelog

All notable changes to USB Watcher are documented in this file.

## [0.1.0] - 2026-07-25

### Added

- Initial Flutter Windows desktop interface
- Rust USB enumeration core based on `nusb`
- JSON communication between Flutter and Rust
- Negotiated USB speed and technology labels
- Device search, manual refresh, and automatic refresh
- USB Watcher application and installer icon
- English-only Inno Setup installation wizard
- Start Menu shortcut, optional desktop shortcut, and uninstaller
- Separate Test Build workflow with one-day artifact retention
- Separate Stable Release workflow
- Installer, portable ZIP, and SHA-256 checksums in release output

### Not included

- Report generation
- Data export
- Telemetry
- Cable certification claims
